📡 Space News API

Documentación de endpoints disponibles

← Volver al inicio

API Status: Activa

Esta API te permite acceder a los artículos de noticias espaciales almacenados en la base de datos. Todos los endpoints devuelven datos en formato JSON.

GET

Obtener todos los artículos

/api/articles

Devuelve una lista completa de todos los artículos guardados en la base de datos.

🚀 Probar endpoint
Ejemplo de respuesta: [ { "id": 1, "handle": "12345", "title": "NASA launches new Mars mission", "authors": [], "url": "https://example.com/news/mars-mission", "imageUrl": "https://example.com/image.jpg", "siteName": "Space News", "summary": "NASA successfully launched...", "publishedAt": "2024-01-15T10:30:00Z" } ]
GET

Obtener y guardar nuevos artículos

/api/fetch

Consulta la API externa de Spaceflight News para obtener los últimos artículos y los guarda en la base de datos. Solo se guardan artículos que no existan previamente.

🚀 Probar endpoint
Ejemplo de respuesta: [ { "id": 15, "handle": "67890", "title": "SpaceX successfully lands rocket", "authors": [], "url": "https://example.com/news/spacex-landing", "imageUrl": "https://example.com/spacex.jpg", "siteName": "SpaceX News", "summary": "SpaceX has successfully...", "publishedAt": "2024-01-16T08:45:00Z" } ]
GET

Contar artículos

/api/articles/count

Devuelve el número total de artículos almacenados en la base de datos.

🚀 Probar endpoint
Ejemplo de respuesta: { "count": 42, "status": "success" }
POST

Eliminar todos los artículos

/api/articles/delete

⚠️ Cuidado: Este endpoint elimina TODOS los artículos de la base de datos. Esta acción no se puede deshacer.

Ejemplo de respuesta: { "message": "Todos los artículos han sido eliminados", "status": "success" }

💡 Notas importantes

  • Todos los endpoints devuelven datos en formato JSON
  • Los artículos se identifican por su handle único para evitar duplicados
  • La API externa que se consulta es: https://api.spaceflightnewsapi.net/v4/articles/
  • Los endpoints GET no requieren autenticación
  • El endpoint DELETE requiere método POST por seguridad
